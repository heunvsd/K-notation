# KNOTATION

VS Code에서 이 폴더를 열고 `index.html`을 Live Server로 실행합니다. 별도 빌드는 없습니다.

처음에는 Gallery가 열립니다. Themes로 처음 이동하면 **Hana Arai × Tetsuko Alice Arisugawa**가 선택되어 있습니다. 이후에는 사용자가 선택한 관계를 유지합니다.

## Themes

- 오른쪽 팔찌나 관계 이름을 선택하면 해당 관계의 기보와 영화 설명이 표시됩니다. 선택 항목은 목록 중앙에 오고 나머지는 위아래로 옅어집니다.
- 12개 관계가 연결되어 있습니다. 목록은 순환하며 휠, 위/아래 화살표, Home/End로도 선택할 수 있습니다.
- ▶/Ⅱ 또는 스페이스 바로 기보를 재생·일시정지합니다. 이미지는 1초마다 전환하고 상단에는 해당 프레임의 타임코드가 표시됩니다. 마지막 이미지에서 멈추며 다시 재생하면 처음부터 시작합니다.
- 관계를 바꾸면 이전 재생이 멈추고 새 관계의 기본 기보로 돌아갑니다. Gallery로 이동할 때도 기보 재생은 멈춥니다.
- 팔찌 MP4는 자동 재생하지 않습니다.
- Elena × Raoul Dorfman은 `기보마지막1` 19장을 19→01로 재생하며, 기본 기보는 01번입니다. 19개의 영화 타임코드는 00:00:00부터 01:26:33까지 대응합니다.
- Yuta × Kou는 `마지막2` 23장을 23→01로 재생합니다. 타임코드는 00:00:00부터 01:46:05까지입니다.
- Kou × Fumi는 `마지막3` 9장을 09→01로 재생합니다. 타임코드 9개는 00:00:00부터 01:32:20까지입니다.
- 하나 × 마사시는 `다시6_…` 19장(19→01), 앨리스 × 켄지는 `다시8_…` 10장입니다. 이 두 묶음을 포함한 모든 기보 이미지는 `assets` 안에 모아 두었습니다. 앨리스 × 켄지의 새 재생 순서는 10→09→08→07→사본→05→04→03→02→01이며, 사본은 기존 05.5와 같은 장면입니다. 기존 타임코드는 모두 유지합니다.
- 리처드 × 엘레나는 새 `다시9_…` 28장(28→01)으로 연결했습니다. 기존 타임코드 28개를 그대로 사용하며, 기본 화면과 재생 종료 화면은 같은 01번입니다.
- 나나미 × 아무로는 `다시5_…` 10장(10→01), 하나 × 앨리스는 `다시7_…` 28장(29→02)으로 연결했습니다. 두 관계 모두 기존 타임코드와 일대일로 대응하며, 흰색 빈 대지인 `다시7-01.png`는 재생에서 제외합니다. 처음 Themes를 열 때도 새 하나 × 앨리스 기보를 표시합니다.
- 재저장 기보: 장해준 × 안정안은 `다시2_…` 24장(24→01), 장해준 × 오수완은 `다시3_…` 8장(08→01), 나나미 × 마시로는 사용자가 지정한 `다시4_…` 25장(25→01)입니다. 세 관계 모두 기존 타임코드 개수와 맞으며, 기본 기보와 마지막 기보는 01번입니다.
- 장해준 × 송서래는 새 `다시1_…` PNG 34장으로 연결했습니다. 순서는 `12-34 → … → 12-03 → 사본 13 → 12-01`이며, 사용자가 지정한 `사본 13.png`가 02번 자리를 대신합니다. 기본 화면과 재생 종료 화면은 같은 `12-01.png`입니다.
- 장해준 × 송서래의 기보 34장은 영화 타임코드 34개에 대응합니다. 재생하면 상단에 첫 장의 `00:00:00`부터 마지막 장의 `02:14:13`까지 각 장면의 시간이 표시됩니다.

## Gallery

- 왼쪽 Gallery를 누르면 검정 배경과 12개 팔찌가 한 패널처럼 왼쪽으로 이동합니다. 전환 중에도 영상은 검정 패널 내부에만 표시됩니다.
- 팔찌는 평면 위에서 각자 다른 속도와 방향으로 부유하고 가볍게 기울어집니다. Z축·원근·앞뒤 확대/축소는 없으며 크기와 밝기는 유지됩니다. 관계 이름은 별도의 레이어에서 흰 글자와 검정 윤곽선으로 표시됩니다.
- 팔찌 크기를 약 1.6배 키웠습니다. 원형 배경 없는 작은 **✥ 손잡이 드래그**로 팔찌 하나의 위치를 옮길 수 있습니다. 화면 밖으로 나간 손잡이는 화면 가장자리에 남고, 클릭하면 해당 팔찌를 중앙으로 가져옵니다. 손잡이에 초점이 있을 때 화살표로 위치 이동, Home으로 중앙 복귀가 가능합니다.
- 처음에는 영상 프레임이 멈춘 채 팔찌 위치만 부유합니다. 팔찌 위 스크롤 입력에만 빠른 회전과 가속·감속을 적용하며, 스크롤을 멈추면 짧게 감속한 뒤 완전히 정지합니다. 자동 반복 재생은 없습니다.
- **빈 공간 드래그**: 전체 배치를 평면에서 이동.
- **팔찌 위 드래그·스크롤**: 해당 팔찌 영상의 회전 각도 조절. 스크롤은 부드럽게 가속·감속하고, 드래그는 손의 이동에 직접 반응합니다. 팔찌에 키보드 초점이 있을 때 화살표나 스페이스로도 회전할 수 있습니다.
- **빈 공간 더블클릭 또는 R**: 전체 팔찌 위치와 배치 초기화. 빈 공간에 초점이 있을 때 화살표로도 배치를 이동할 수 있습니다.
- **Themes 또는 Escape**: 테마 화면으로 복귀. About을 선택하면 여덟 기호와 한글 소개가 같은 화면에 나타납니다.
- 우측 상단·좌측 하단 안내 문구, 호버 팝업, 갤러리 내 기보 열기, 종이접기는 없습니다.
- 시스템의 동작 줄이기 설정에서는 전환 애니메이션과 자동 부유를 생략하고, 스크롤은 감속 잔여 동작 없이 직접 적용합니다.

## About

- About을 열면 여덟 매듭 기호가 바로 위에서 떨어지고 오른쪽 위에서 소개 글 네 문단을 한 단으로 읽을 수 있습니다. 기호는 화면 아래에 낮고 넓게 쌓입니다. 왼쪽은 조금 더 촘촘하고, 오른쪽 끝까지 서로의 획에 닿아 하나로 이어집니다.
- 기호는 화면 밖에서 자기 자리로 곧장 떨어져 바닥이나 다른 기호의 획에 닿으면 그 자리에서 멈춥니다. 약 0.13초 간격으로 등장하며, 바닥층의 세 번째 기호 뒤에서만 약 0.23초를 기다립니다. 메뉴에서 About으로 돌아오면 낙하를 다시 시작합니다.
- 기호 이미지에 마우스를 올리거나 터치하면 해당 기호의 획 위에 210 자막으로 한글 설명이 뜹니다. 각 기호에 한 문장씩, 오른쪽 위 본문과 같은 글자 크기로 표시합니다. 겹친 고리 안에서는 가까운 획을 선택합니다. 기호가 바닥이나 다른 획에 받쳐져 가라앉으면 그 위치에서 멈춥니다. 드래그하면 가까운 선을 잡아당기며, 놓은 기호는 중력을 받아 떨어집니다. 아래 기호를 옮기면 지지를 잃은 기호도 함께 떨어집니다. 키보드에서는 Tab으로 선택하고 화살표로 움직이며, 동작 줄이기 설정에서는 낙하가 끝난 배치만 표시합니다.
- About은 SVG 원본을 표시하고, 같은 파일의 검은 면을 작은 볼록 다각형으로 나누어 충돌을 계산합니다. 고리 안과 흰색 끝점 내부는 비워 둡니다. Approach부터 Hesitation까지 기존 그림에 대응하는 SVG 파일 번호는 8, 1, 2, 3, 4, 5, 6, 7입니다. SVG 윤곽을 수정한 뒤 프로젝트 폴더에서 `python3 tools/trace-symbols.py`를 실행해 `symbol-ink.js`를 갱신하세요(fonttools, Shapely 2.1 이상 필요). 물리 엔진은 `vendor/`에 포함되어 인터넷 연결 없이 동작하며, About을 처음 열 때 불러옵니다.
- About에서 Themes 또는 Escape로 돌아오면 기존 관계와 기보 프레임을 유지합니다. Gallery와 About 사이를 이동할 때는 검은 갤러리가 슬라이딩됩니다.
- 한글 소개와 기호의 호버 설명은 210 자막 Bold를 사용합니다. 본문의 자간은 -20이며, 글자 주변에서만 배경을 밝게 해 기호와 겹쳐도 읽을 수 있게 합니다.
- 210 자막은 Adobe Fonts 웹 프로젝트 `vkf7mtu`에서 불러옵니다. CSS 이름은 `jamak`, Bold의 웹 굵기는 `500`입니다. 방문자의 Creative Cloud나 로컬 폰트 설치는 필요하지 않습니다. 인터넷 연결이 없거나 Adobe Fonts를 불러오지 못하면 로컬 폰트 또는 시스템 폰트로 표시합니다. 호버할 때 새로 나타나는 한글도 Adobe의 동적 서브셋으로 불러옵니다.
- 소개 문구는 `index.html`, 레이아웃과 전환은 `about.css`와 `script.js`에서 수정합니다.

- `index.html`: 화면 구조와 두 화면 위에 유지되는 제목·메뉴.
